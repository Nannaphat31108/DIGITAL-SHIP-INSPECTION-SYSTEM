Ship Structural Damage Assessment

Enter damage data → the system calculates thickness reduction, damage score, severity and preliminary status.

⚠
Educational preliminary assessment only. Scores and thresholds are simplified rules defined for learning purposes. They do not certify the safety of any vessel and do not replace a classification society surveyor or qualified engineer. (การประเมินเบื้องต้นเพื่อการศึกษา ไม่ใช่การรับรองความปลอดภัยของเรือ)

Calculation Method

Thickness diminution
Δt = t₀ − tₘ    Δt% = (t₀ − tₘ)/t₀ × 100
t_min = t₀ × (1 − allowable%/100)
Margin ratio = Δt% / allowable%  (≥0.75 substantial, >1 exceeds)
Corrosion rate = Δt / years    Remaining life = (tₘ − t_min)/rate
Measurement score M (0–100)
Corrosion: 75 × ratio  |  Crack: 40 + L/8 (+20 through)
Dent: 7.5 × (depth/width × 100)  |  Coating: 1.5 × area%
Weld: 30 + L/10 (+25 through)
Final score
S = min(100, M × f_member × f_zone)
f_member: primary 1.25 · secondary 1.00 · tertiary 0.75
f_zone: midship 0.4L 1.15 · aft/forward 1.00
Severity: S ≥ 75 Critical · ≥ 50 High · ≥ 25 Moderate · < 25 Low

Formulas Used

∇ = L·B·T·CB    Δ = ρ·∇    (Draft mode)
T = Δ / (ρ·L·B·CB)    (Displacement mode)
AWP = CWP·L·B    TPC = ρ·AWP/100
KB = T·(5/6 − CB/(3·CWP))  Morrish
IT ≈ CWP²·L·B³/12    BM = IT/∇
KM = KB + BM    GM = KM − KG    GMf = GM − FSC
GZ(φ) = sin φ·(GMf + ½·BM·tan²φ)  wall-sided
φdeck edge = atan((D − T)/(B/2))
Troll = 2·C·B/√GMf, C = 0.373 + 0.023·B/T − 0.043·L/100
Reference criteria: IMO IS Code 2008 — GM₀ ≥ 0.15 m; area 0–30° ≥ 0.055 m·rad

About this Project

Digital Ship Inspection & Engineering Analysis System is a single-page web application developed as an engineering portfolio project. It is built with HTML, CSS and vanilla JavaScript only — no server, no database, no login. All data are stored in the browser's LocalStorage.

Module 1Digital Ship Inspection System
Module 2Ship Structural Damage Assessment
Module 3Preliminary Ship Design / Stability Simulation
TechnologyHTML5 · CSS3 · JavaScript (ES5) · SVG
StorageBrowser LocalStorage
⚠
All calculations are simplified and for educational purposes only. Results must not be used to certify seaworthiness, structural adequacy or stability of a real vessel.

References (for study)

  • IMO, International Code on Intact Stability (IS Code) 2008 — GM₀ ≥ 0.15 m, area 0–30° ≥ 0.055 m·rad, roll period coefficient.
  • Morrish's approximation for the vertical centre of buoyancy (KB).
  • Wall-sided formula for GZ at moderate heel angles.
  • IACS Recommendation 87 / URZ10 concepts — "substantial corrosion" (wastage beyond 75% of allowable margin) and coating condition GOOD/FAIR/POOR.
  • Barrass & Derrett, Ship Stability for Masters and Mates.
  • IMO number check-digit scheme (weights 7-6-5-4-3-2).
